## Задания

### Задание 6. Множество на основе односвязного списка

Реализовать структуру данных «Множество» на основе односвязного списка. Обращение к элементам должно производиться через дандерные (магические) методы Python. Реализовать 2 варианта проверки вхождения элемента. Добавить методы `intersect` (пересечение) и `union` (объединение).

### Задание 12. Двусвязный список

Реализовать структуру данных «Двусвязный список». Обращение к элементам через дандерные методы Python. Реализовать 2 варианта проверки вхождения элемента.

Требования к каждому заданию: минимум 5 тестов, 2 бенчмарка, использование Type Hinting.

## Реализованные структуры

### MySet — множество на односвязном списке

Узел `Node` хранит значение `value` и ссылку на следующий узел `next`.
Класс `MySet` хранит только голову `head`.

**Методы:**
- `add(value)` — добавление элемента без дубликатов
- `__len__` — длина через `len(s)`
- `__contains__` — проверка вхождения через `5 in s`
- `contains(item)` — второй вариант проверки (обычный метод)
- `__repr__` — вывод в формате `{1, 2, 3}`
- `intersect(other)` — пересечение множеств
- `union(other)` — объединение множеств

### DoublyLinkedList — двусвязный список

Узел `Node2` хранит `value`, `next` и `prev`.
Класс `DoublyLinkedList` хранит `head` (голова) и `tail` (хвост).

**Методы:**
- `add(value)` — добавление в конец за O(1), потому что есть `tail`
- `__len__`, `__contains__`, `contains`, `__repr__`

## Сложность операций

| Операция       | MySet | DoublyLinkedList |
|----------------|-------|------------------|
| `add`          | O(n)  | O(1)             |
| `__len__`      | O(n)  | O(n)             |
| `__contains__` | O(n)  | O(n)             |

**Пояснение:**

- `MySet.add` — O(n), потому что нужно пройти весь список: либо чтобы проверить дубликат, либо чтобы дойти до конца и привязать новый узел.
- `DoublyLinkedList.add` — O(1), потому что есть ссылка на хвост `tail`. Новый узел привязывается к хвосту сразу, без обхода списка.
- `__len__` и `__contains__` в обеих структурах — O(n), так как идут от головы до конца.

Разница в скорости видна в бенчмарках: добавление 10000 элементов в `MySet` занимает секунды, а в `DoublyLinkedList` — миллисекунды.
